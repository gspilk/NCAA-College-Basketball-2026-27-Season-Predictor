How to enter games
1. Find the conference's full schedule on its official website (often one page or PDF). Copy it by hand or use the site's download; don't write a scraper.
2. Open data\schedule\M_schedule_2027.csv in Excel and add one row per game. Each game once is enough; a game listed twice is only counted once.
3. Save as CSV, then run python schedule.py. It reports how many real games it found and lists any team names it didn't recognize.
4. Set that conference's Status to Done once the check shows no unrecognized names.
